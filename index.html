นำเข้าไฟล์จาก Google Drive

ดึงไฟล์ HEIC/HEIF จากลิงก์แชร์ โฟลเดอร์ หรือบัญชี Drive ของคุณ

ไฟล์หรือโฟลเดอร์ต้องตั้งค่าแชร์เป็น "ทุกคนที่มีลิงก์ (ผู้มีสิทธิ์อ่าน)"

ใช้สำหรับเลือกไฟล์ส่วนตัวใน Google Drive ของคุณโดยตรง (ไม่ต้องเปิดแชร์สาธารณะ) แนะนำให้เปิดไฟล์ HTML นี้ผ่านโดเมนของคุณ เช่น GitHub Pages เพื่อล็อกอินบัญชี Google ได้สมบูรณ์
วิธีสร้าง API Key / Client ID ใน Google Cloud (ทำครั้งเดียว)
  1. เข้า Google Cloud Console แล้วเปิดใช้งาน Google Drive API (และ Google Picker API หากใช้แบบเลือกจากบัญชี)
  2. ไปที่เมนู Credentials → สร้าง API Key เพื่อนำมาใช้ดึงไฟล์/โฟลเดอร์จากลิงก์แชร์
  3. หากต้องการเลือกไฟล์ส่วนตัวโดยไม่เปิดแชร์ ให้สร้าง OAuth 2.0 Client ID (Web application) และเพิ่ม URL เว็บของคุณใน Authorized JavaScript origins
